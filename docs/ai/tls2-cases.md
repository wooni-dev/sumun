# TLS-2 보안·경계 사례: 루트 CA 생성·보관 (O10: 검토 에이전트 제안)

출처: 2026-11-08, 별도 컨텍스트의 검토 에이전트가 **명세만 보고** 제안(51개 + 결정 15개) [추측: 코드 없음]. 근거: [RFC] 5280, [함정] node-forge·Node·Windows에서 흔한 실수(구현 전 실측으로 확인).
명세: `loadOrCreateCA(dir)` → `{ certPem, keyPem }`. dir에 CA 인증서·키가 있으면 읽고, 없으면 새 루트 CA(자체 서명, 1년, CA 용도)를 만들어 저장. 기본 위치 `%LOCALAPPDATA%\sumun\ca\`. Windows 저장소는 건드리지 않는다.
배정: **2** = TLS-2, **2b** = TLS-2b(쓰기 견고성·권한 — 2026-11-08 나눔), **3** = TLS-3, **등록** = SEC-3, **UI** = 대시보드 단위, **hook** = 별도 작은 단위(제안).
