# [UI-7] 호스트 필터 0건 안내        커밋: 54f3a5b..(이 문서 커밋)

## 한 줄 요약
대시보드의 호스트 필터에 `z-emotion`처럼 이름 일부만 넣어 0건이 나오면, 목록 아래에 "호스트는 도메인 전체로 찾습니다. 예: example.com…" 안내가 나옵니다. 필터가 찾는 규칙은 바꾸지 않았습니다(UI 보고서 결정 23).

## 화면에서 바뀐 것
```
 호스트 [ example      ]  [필터 적용]            필터 결과 0건
 ┌──────────────────────────────────────────────┐
 │ (빈 목록)                                     │
 └──────────────────────────────────────────────┘
 호스트는 도메인 전체로 찾습니다. 예: example.com을 넣으면
 www.example.com 같은 하위 도메인도 함께 나옵니다. 이름 일부(example)로는 찾지 않습니다.
```
- 안내는 **호스트 조건을 적용했고 결과가 0건일 때만** 나옵니다. 메서드·상태만 걸어서 0건이면 나오지 않습니다(그때는 호스트 규칙과 관계가 없으니까요).
- 기준은 입력 칸이 아니라 **적용된 조건**입니다. 칸에 글자만 바꾸고 "필터 적용"을 누르지 않으면 목록도 안내도 그대로입니다.
- 문구는 고정입니다. 입력한 글자를 문구에 넣지 않으므로, 이상한 글자를 넣어도 화면에 그대로 되비치지 않습니다.
- 목록이 너무 커서 "최근 n건만 보입니다" 안내가 필요할 때는 그 안내가 먼저입니다(0건일 때는 겹치지 않음).

## 왜 부분 일치로 바꾸지 않았나
`ample.com`이 `example.com`에 걸리는 것처럼 글자 포함 검색은 엉뚱한 사이트를 섞을 수 있고, 저장소의 필터 규칙(STO)까지 바꿔야 합니다. 안내 한 줄로 "도메인 전체를 넣으면 하위 도메인까지 나온다"는 것만 알려 드리기로 했습니다(2026-11-09 승인).
