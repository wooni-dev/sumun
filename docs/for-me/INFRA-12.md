## O50을 기계가 보는 방법
```
 작은 단위 검사 merge-record (check-method --id <ID>)
   규칙 도입(INFRA-12 계획 c7c0522) 전 작업 ──▶ ➖ 규칙 도입 전
   아직 병합 전                                ──▶ ➖ 병합 전
   병합함 + "[ID] 병합 뒤 기록" 커밋 있음       ──▶ ✅
   병합함 + 기록 없음                          ──▶ ➖ 기록 대기  ← 병합 직후 검사에서는 이게 정상
 큰 단위 검사 merge-records (check-method --id STO 같은 것)
   하위 노드 중 "기록 대기"가 하나라도 있으면  ──▶ ❌ (그 노드 ID를 적음)
```
- 작은 단위에서 ❌가 아니라 ➖인 이유: 검사는 보통 **병합 직후, 기록을 남기기 전에** 돌리기 때문입니다. 그때 ❌가 나오면 늘 실패하게 됩니다. 빠진 기록은 큰 단위가 끝날 때 ❌로 잡습니다.
- INFRA 노드는 큰 단위 검사가 없어서, 감사 에이전트가 직접 봅니다.
