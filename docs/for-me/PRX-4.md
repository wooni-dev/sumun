# [PRX-4] 실행 진입점 `npm start`        커밋: 1833765..(이 문서 커밋)

## 한 줄 요약
이제 **`npm start`로 프록시를 띄울 수 있다.** 터미널에 시작 줄 하나와, 요청마다 요약 한 줄이 나온다. 요약 줄에는 메서드·목적지·상태·시간만 나온다. 쿠키, 경로, 쿼리는 나오지 않는다.

## 써 보기
```
npm start                     ← 127.0.0.1:8080
npm start -- --port 9000      ← 다른 포트 (-- 를 꼭 붙인다. 없으면 npm이 --port를 가져가서 8080으로 뜬다)
```
실제 출력 (`node scripts/probe/prx4-npm-start.mjs`, 쿠키·경로·쿼리·userinfo에 표식을 넣고 보낸 요청):
```
sumun: 127.0.0.1:18096 에서 프록시를 시작했습니다. 브라우저 프록시를 이 주소로 설정하세요. 끝내려면 Ctrl+C
19:53:48 GET 127.0.0.1:18097 200 18ms
19:53:48 GET 127.0.0.1:1 unreachable 502 3ms
```
표식은 출력에 0번 나왔다 [확인됨].

**지금 브라우저로 쓸 때의 한계**: HTTPS 사이트는 아직 지원하지 않는다(501). `http://`로 시작하는 사이트만 보인다. HTTPS는 다음 큰 단위(TLS)에서 한다.
**권장 설정**: Windows 전체 프록시를 바꾸면 다른 프로그램(업데이트, 메신저)의 트래픽도 이리로 온다. 시험할 때는 **Firefox의 자체 프록시 설정**(설정 → 네트워크 설정 → 수동 프록시: HTTP 127.0.0.1, 포트 8080)을 쓰거나 `curl -x http://127.0.0.1:8080 http://...`을 쓴다.

## 요약 줄에 왜 이것만 나오나
기록에는 쿠키·토큰이 원본 그대로 있다(PRX-2 결정). 터미널은 화면 공유, 스크롤 기록, 리다이렉트(`> log.txt`)로 쉽게 밖에 나간다. 그래서:
- **경로·쿼리를 쓰지 않는다**: `?token=...`, `/reset/<토큰>`처럼 경로에 비밀이 흔하다.
- **호스트는 실제로 연결한 대상(target)에서 쓴다**: Host 헤더나 원문 URL을 쓰면 `http://user:비밀번호@host/`의 비밀번호가 나온다.
- **이상한 글자는 `\x1b`처럼 보이게 바꾼다**: 터미널은 ESC로 시작하는 글자로 화면을 지우거나, 클립보드에 쓰거나(Windows Terminal의 OSC 52), 앞 줄을 덮어쓸 수 있다. 웹 개발로 치면 **터미널판 XSS**다. 출력 가능한 ASCII만 그대로 두고 나머지는 전부 바꾼다(한글도 `\u{d55c}`로 바뀐다 — 호스트는 punycode라 실제로는 거의 생기지 않는다).

## 포트 검사 (A10)
`1`~`65535`의 정수를 십진수 글자 그대로만 받는다. 거부하는 예: `0`, `65536`, `-1`, `8080abc`, `8080.0`, `1e3`, `0x1F90`, `+8080`, `08080`, `" 8080 "`, 전각 `８０８０`, `--port` 두 번, `--host 0.0.0.0` 같은 모르는 인자. 자바스크립트의 `Number()`·`parseInt()`는 `0x1F90`을 8080으로, `""`를 0으로 바꿔 버려서 정규식으로 글자부터 검사한다.
